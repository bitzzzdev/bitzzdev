# Contributing to bitzzdev

Thank you for your interest in contributing to this project.

## Workflow

1. Fork the repository and create your branch from `preview`.
2. Install dependencies with `npm install`.
3. Verify your changes build cleanly using `npm run build` and pass typechecks with `npm run typecheck`.
4. Ensure clean writing without em dashes or decorative emoji in documentation.
5. Submit a pull request against the `preview` branch with a clear description of changes.

## Reporting Issues

If you find a bug or layout discrepancy, please open an issue on GitHub with reproduction steps and browser details.
