# Security Policy

## Supported Versions

Security updates are applied to the active branch (`ascii` for production and `preview` for staging).

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. Do not open a public issue.
2. Email details of the vulnerability to bitzzdev@gmail.com.
3. Include clear steps to reproduce and any relevant code snippets.

You will receive an acknowledgment within 48 hours, followed by updates on mitigation and release timelines.
